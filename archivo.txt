Trabajo
1. La misma instrucción para dos modelos de IA

Copien esta instrucción, igual, en dos asistentes de IA distintos: «Escribe un programa en Python que pida tres números enteros y los muestre de menor a mayor. Usa solo input, if, else y comparaciones: sin listas, ciclos ni sorted(). Explica en tres líneas cómo funciona.»

Desarrollo
1.En claude
a = int(input("Primer número: "))
b = int(input("Segundo número: "))
c = int(input("Tercer número: "))

if a > b:
    a, b = b, a
if b > c:
    b, c = c, b
if a > b:
    a, b = b, a

print("De menor a mayor:", a, b, c)
1.Se leen los tres números y se convierten a enteros con int(input(...)).
2.Primero se comparan a y b (y luego b y c), intercambiándolos si están en desorden; así el mayor de los tres termina en c.
3.La última comparación entre a y b los deja ordenados, y se imprimen de menor a mayor.

2.En chatGPT
a = int(input("Ingresa el primer número: "))
b = int(input("Ingresa el segundo número: "))
c = int(input("Ingresa el tercer número: "))

if a <= b and a <= c:
    if b <= c:
        print(a, b, c)
    else:
        print(a, c, b)
else:
    if b <= a and b <= c:
        if a <= c:
            print(b, a, c)
        else:
            print(b, c, a)
    else:
        if a <= b:
            print(c, a, b)
        else:
            print(c, b, a)
1.input() pide los tres números y int() convierte cada entrada en un entero.
2.Las condiciones if, else y las comparaciones determinan cuál número es menor, intermedio y mayor.
3.Finalmente, print() muestra los tres números ordenados de menor a mayor.
